# Briefing

### Contexto



La fragmentación de herramientas dificulta la organización personal diaria.



### Problema



El problema que se nos presenta es la inexistencia de un panel que nos centralice nuestros planes, tareas, finanzas y la información clave sin complicarlo todo mucho.



### Actor



El usuario será finalmente el actor, pues será el que utilice la aplicación para planificar su día a día, registrar gastos, etc.



### Objetivos



* Unificar en una sola aplicación 5 módulos clave: eventos, tareas, gastos, notas y un resumen
* Garantizar la carga instantánea y la persistencia de datos local
* Ofrecer una visualización clara de métricas globales



### Alcance



* Planes/Eventos: Registro y consulta de fechas y planes
* Tareas: Gestión de tareas pendientes (crear, completar, eliminar)
* Gastos: Registro de los distintos gastos y calcular total
* Información personal: Almacenamiento de notas y datos útiles
* Resumen: Panel centralizado con las distintas métricas



### Restricciones



* Arquitectura SPA en JavaScript Vanilla
* Vite como herramienta de construcción
* Estado global compartido en cliente entre las distintas funciones



### Recursos



* APIs nativas de navegador
